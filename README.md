## Dreamy Treats — Online Bakery Web Application

**Dreamy Treats** is a modern, responsive web application for an online bakery. Built with React and Vite, it offers an intuitive browsing experience for fresh bakery items, seamless ordering, and customer feedback collection.

## Key Features
* Interactive Hero & Branding: Fast navigation to fresh-baked daily specials and order CTA.
* Categorized Menu: Clear sectioning for **Breads**, **Pastries**, **Desserts**, and **Cakes** with individual pricing and descriptions.
* Online Ordering Form: Built-in order submission interface with input validation for emails, product selections, quantities, and delivery notes.
* Interactive Feedback System: Custom sentiment rating scale utilizing emoji selectors to collect customer impressions.
* Fully Responsive UI:Styled with clean layout principles to ensure seamless viewing across mobile, tablet, and desktop devices.
  
**Tech Stack:**
Frontend:React, JavaScript (ES6+), HTML5, CSS3
Build Tool: Vite
Version Control: Git & GitHub
